# OranjSvensk Scoop Bucket

Personal [Scoop](https://scoop.sh/) bucket for [ezbx](https://github.com/OranjSvensk/ezbx) — boxed-up local AI agents.

## Install

```powershell
scoop bucket add ezbx https://github.com/OranjSvensk/scoop-bucket
scoop install ezbx
```
